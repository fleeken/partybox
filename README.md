# Partybox

Online-first party game for 2–8 players. A TV/browser shows the game while phones act as controllers.

## MVP
- Create/join lobby with short code
- TV host view + mobile controller view
- Realtime communication with Socket.IO
- Player colors and scores
- Voting between minigames
- First test minigame: Stoppa på 10.00

## Run locally
```bash
npm install
npm run dev
```
Then open `http://localhost:3000`.
